# CRUD Angular Material

Aplicação de cadastro de pessoas desenvolvida com **Angular** e **Angular Material**, com o objetivo de praticar conceitos de CRUD, formulários, componentes e consumo de API.

## Funcionalidades

* Cadastro de pessoas
* Consulta de pessoas cadastradas
* Exclusão de pessoas
* Armazenamento dos dados no `LocalStorage`
* Consulta de UFs (estados) e municípios através da **BrasilAPI**
* Cadastro dos seguintes dados:

  * Nome
  * E-mail
  * CPF
  * Data de nascimento
  * UF
  * Município

## Tecnologias utilizadas

* Angular
* Angular Material
* TypeScript
* HTML
* CSS
* LocalStorage
* BrasilAPI

## BrasilAPI

A aplicação utiliza a [BrasilAPI](https://brasilapi.com.br/docs) para consultar os estados brasileiros e os municípios de acordo com a UF selecionada.

## Objetivo

Projeto desenvolvido para praticar e consolidar conhecimentos em **Angular**, utilizando componentes do **Angular Material**, serviços, formulários, armazenamento local e integração com uma API externa.
